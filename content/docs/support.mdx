# Support

Need help with a Vexaro resource?

Our documentation covers installation, configuration and common problems.

## Discord Support

For additional help, contact the Vexaro support team through our Discord server.

When asking for support, include:

- The Vexaro resource you are using
- What you were trying to do
- What happened
- Any error messages
- Relevant console output

This helps us diagnose the problem faster.
