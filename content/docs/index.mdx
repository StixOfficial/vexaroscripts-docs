# Introduction

Welcome to **Vexaro Scripts**.

We create modern, reliable and easy-to-use FiveM resources designed to improve the experience of both server owners and players.

Our goal is simple: build high-quality scripts that are easy to install, simple to configure and packed with useful features.

Whether you are starting a new FiveM server or improving an established community, Vexaro Scripts provides resources built with performance, usability and quality in mind.

## About Us

Vexaro Scripts is a FiveM development studio focused on creating resources for the FiveM community.

We are constantly working on new scripts, improvements and updates to provide server owners with better tools and more possibilities.

We believe good resources should be reliable, straightforward and enjoyable to use. Every Vexaro resource is developed with those principles in mind.
